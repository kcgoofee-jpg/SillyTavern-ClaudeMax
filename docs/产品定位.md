# 产品定位

> 初版 · 2026-09-26（v3.0.0）。评审意见和修改记录在文末。

## 一句话

**让酒馆里的 Claude 角色扮演更省、更稳、跨设备不断线。**

SillyTavern / TauriTavern 的一个扩展（面板）+ 一个可选的本机代理 + 一套一键脚本。面板对任何 Claude 连接都有用；配上代理，可以用自己的 Claude 订阅玩，并解锁缓存排布、手机防丢回复、Mac ↔ 手机同步。

## 给谁用

| 用户 | 现在的痛点 | 这里给的 |
| --- | --- | --- |
| **订阅玩家**（主力）：有 Claude Pro / Max，Mac 当主机，手机上用 TauriTavern 玩 | 订阅不能直接接酒馆；长聊天每轮重写十几万 token，慢；手机切后台回复就丢；电脑和手机的聊天、卡、预设两头不一致 | 代理（走自己的订阅）、缓存排布、防丢回复、手机模式和同步、一键脚本 |
| **API 玩家**：直连 Claude API 或 OpenRouter，不想跑代理 | 新模型、预设和模型对不上；Opus 5 / 5.5 遇到「把思考写进正文」的条目直接拦截，还照样计费；卡里藏着未成年设定 | 只装面板：按预设切模型、发送前检查、体检、角色卡检查、灵动岛 |

不面向：多人共享一个订阅、做成对外服务、需要多账号轮换的用户。

## 三层能力

1. **面板**（`src/panel/`，任何 Claude 连接都能用）
   模型切换与「预设推荐模型」；发送前检查（Opus 5 / 5.5 会拦的条目，指出原句）；体检（正文字数 / 段数、镜头卡、选项、界面大小、性能）；角色卡检查（未成年与幼态化，卡和世界书都查）；灵动岛（生成进度、字数、用时、缓存）。
2. **代理**（`src/proxy/`，用订阅时需要）
   OpenAI 兼容接口，背后是官方 Claude Code / Agent SDK；会话续接；**缓存排布**（每轮变化的世界书挪到后面，前面的长提示词一直命中）；**防丢回复**（手机断开时代理写完并保存，回到 App 补回）；额度、用量和缓存诊断；手机遥控 Mac。
3. **工具箱**（`launcher/`，可选）
   Mac 一键安装 / 启动 / 检查；手机模式（局域网 + 访问密码、防睡眠、掉线自启、合盖不睡）；Mac ↔ 手机全自动同步；安卓保活模块（独立仓库 [tt-root-module](https://github.com/kcgoofee-jpg/tt-root-module)）。Windows / Termux 为实验性。

## 和别的方案比

| 方案 | 它做什么 | 我们的差别 |
| --- | --- | --- |
| 酒馆自带的 Claude 源 / OpenRouter | 直连 API，自带缓存（含 1 小时）| 面板在它上面照样能用；我们不重复做缓存设置 |
| 原作者 [SillyTavern-Subscriptions](https://github.com/LukaTheHero/SillyTavern-Subscriptions)（Claude / Codex / Gemini 订阅合一）| 订阅接入、额度用完自动切 API | 我们专注 Claude 角色扮演：缓存排布、手机防丢、同步、体检 |
| CLIProxyAPI、Meridian、ClewdR 等通用反代 | 把订阅包成通用 API，面向编程客户端或多账号 | 不做多账号 / 共享；针对酒馆的提示词结构和手机场景做优化 |

## 不做的事（边界）

- 不做订阅共享、拼车、多账号轮换，不做对外服务。
- 不规避安全机制：模型拒绝时不自动换模型重试；发送前检查只提醒，不改写内容。
- 不导入、不调整涉及未成年人的角色卡和世界书。
- 长期记忆、总结、变量解析交给预设和专门插件（记忆 / 数据库、MVU）；生图交给柏宝绘等生图扩展。扩展不偷偷改动酒馆拼好的提示词内容，只做位置排布，并且可关。

## 合规

用订阅登录，Anthropic 条款只明确允许原版 Claude Code；用 Agent SDK 的开发者被要求用 API 密钥。个人自用订阅属于灰色地带，共享明确禁止。README 写明风险；介意的用户在密钥栏填 `sk-ant-…` 即按 API 计费（缓存自动用 1 小时）。
